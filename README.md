# Пульс новичка

Ранний сигнал о том, что новичок может уйти в первые три месяца.

Задача о приёме в Битрикс24 запускает короткий опрос новичка в Telegram. Если опрос провален, руководитель
получает задачу «поговорить с новичком» с конкретной проблемой. Если провалов у одного новичка два и больше,
дополнительно получает задачу HR.

## Как устроено

- **Бот «Новичок СпортОпт»** ([@Novicheksportopt_bot](https://t.me/Novicheksportopt_bot)): при оформлении новичок
  получает одну общую ссылку на бота, нажимает «Старт» и «Поделиться номером». Бот находит его карточку по телефону
  и дальше шлёт опросы именно ему. Принимается только собственный номер пользователя, пересланный чужой контакт
  отклоняется. Сервер забирает сообщения из Telegram через long polling, публичный адрес для этого не нужен.
- **Эмуляция Битрикс24** (`/bitrix`), три раздела:
  - **Новички**: список, телефон и статус подключения бота, кнопка «Отправить опрос», которая эмулирует
    исходящий вебхук Битрикса, история ответов.
  - **Руководители**: задачи по проваленным опросам их новичков.
  - **HR**: сводка и задачи по новичкам с 2+ провалами.
- **Опрос** (`/survey/:token`): 4 вопроса, ответы «Да / Нет / Не знаю», необязательный комментарий.
  Страница рассчитана на телефон.
- **Скоринг** ([shared/survey.js](shared/survey.js)):
  - каждый вопрос весит 25%; «Да» даёт 100% веса, «Не знаю» 30%, «Нет» 0%;
  - опрос провален, если есть хотя бы одно «Нет» или итог меньше 80%.
- **Правила задач** ([server/service.js](server/service.js)):
  - провал создаёт задачу руководителю со сроком 2 рабочих дня;
  - 2+ провала у одного новичка создают задачу HR, пока предыдущая задача HR открыта, новая не создаётся.

Стек: React + Vite, Express, SQLite (встроенный `node:sqlite`, Node 22.13+). Данные выдуманные и
пересоздаются кнопкой «Сбросить демо-данные».

## Запуск

```bash
npm install
cp .env.example .env   # вписать TELEGRAM_BOT_TOKEN
npm run dev            # http://localhost:5173
```

Бот создаётся у [@BotFather](https://t.me/BotFather): `/newbot`, имя «Новичок СпортОпт», username на `bot`.
Без токена всё работает, только ссылка на опрос показывается прямо в таблице.

Чтобы открыть ссылку из Telegram на телефоне, нужен публичный адрес: деплой или туннель
(например, `cloudflared tunnel --url http://localhost:5173`). Его нужно указать в `PUBLIC_URL`.

## Продакшен

```bash
npm run build
npm start              # Express отдаёт и API, и собранный фронтенд на PORT
```

## Тесты

```bash
npm test
```

Тесты проверяют крайние случаи скоринга, создание задач руководителю и HR без дублей, запрет повторного
прохождения опроса, повторное использование неотвеченного опроса при повторном вебхуке, нормализацию телефонов
и привязку Telegram по номеру.
